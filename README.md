# FlowCapital AI

Intelligence that moves with every asset.

Module 1 is a premium frontend foundation for an agentic supply-chain working capital platform. It uses local TypeScript mock data only — no FastAPI, Supabase, or LLM calls yet.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Enter Command Center at `/dashboard`.

## Stack

Next.js App Router · TypeScript · Tailwind CSS · shadcn/ui · Framer Motion · Lucide · Recharts · React Flow (installed, unused until later modules)
